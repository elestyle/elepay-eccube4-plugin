# Follow-up after the EC-CUBE 4.4 GA release

The plugin code supports EC-CUBE 4.2 / 4.3 / 4.4. 4.4 is still alpha; its GA release is planned for 2026-11. The items below have to be done after the GA release. Delete this file once all of them are done.

## 1. 「戻り先URL」 for 4.4 on the EC-CUBE store

- **Current state**: `docs/eccube-store.md` only has the 4.2 / 4.3 values (`check81` / `4.3.1`). For 4.4 it says to confirm with the store's current instructions. Submissions made before the 4.4 GA release keep using the 4.3 values.
- **Open questions**:
  - Verification environment: no public source lists one for 4.4. `check85.ec-cube.net` exists, while `check82`–`check84` do not, so it is probably the 4.4 (PHP 8.2–8.5) environment. This is unconfirmed.
  - Version ②: the last EC-CUBE version the plugin supports. After the GA release this should be `4.4.0`, or the latest 4.4.x at that time.
- **To do**:
  - [ ] After the 4.4 GA release, ask the store office (オーナーズストア事務局) which verification environment and version to use.
  - [ ] Write the answer into the "Value for this plugin" section of `docs/eccube-store.md` and remove the "confirm with the store" note.
